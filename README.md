# Learning VLM Post-Training with GRPO

A step-by-step learning project for post-training a vision-language
model using Group Relative Policy Optimization (GRPO).

Based on the Hugging Face tutorial:
[Post-training a VLM for reasoning with GRPO using TRL](https://huggingface.co/learn/cookbook/en/fine_tuning_vlm_grpo_trl).

## Learning goals

- Understand the dataset, model, reward functions, and GRPO training.
- Build an installable Python package with a Colab notebook.
- Manage Python and dependencies with uv.
- Practice Git branches, meaningful commits, and pull requests.
